# Cartoon typography sources

The Unity-facing TTF files are deterministic static instances generated by
`generate_static_fonts.py` from the pinned Google Fonts upstream sources below.

| Family | Upstream commit | Source file |
|---|---|---|
| Montserrat | `cc8daf2e7085006b9c112542fc82b58afc13521d` | `fonts/variable/Montserrat[wght].ttf` |
| Plus Jakarta Sans | `18d1cd2f7ea10481919d2f05c1f7064b7307fc26` | `fonts/variable/PlusJakartaSans[wght].ttf` |
| Noto Sans | `c4a321e123e4d4ff315f57f4e0adf294fe3a95be` | `NotoSans/googlefonts/variable-ttf/NotoSans[wdth,wght].ttf` |

All three families are licensed under the SIL Open Font License. The exact
license files are stored beside their source fonts. Do not replace the pinned
sources without regenerating and visually re-verifying every Cartoon screen.
