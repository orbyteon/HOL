# HOL visual references

The approved HOL product direction is the Cartoon Theme defined in `design/cartoon-theme.md`.

Reference screenshots and mockups are design evidence only. Runtime Unity must use approved text-free production assets with live TMP localization and must follow the Production UI Asset Fidelity Contract in `AGENTS.md`.

For onboarding, the approved direction is an actual interactive setup flow (nickname, age, identity/preferences, confirmation) in the same neon-cartoon HOL style as the game: large HOL logo, expressive cartoon characters, chunky glossy controls, deep plum/indigo background, cyan/magenta/violet accents, gold primary CTA, and sparse number/lightning/star/confetti motifs. A robot shown in mockups is not a runtime production asset until a dedicated approved robot file is committed.
