# Ads and consent utility icons

- `ad_label.svg`: transparent advertising disclosure label
- `close.svg`: clear close affordance
- `skip.svg`: post-match skip control
- `info.svg`: ad/privacy information affordance
- `privacy_shield.svg`: consent and privacy settings
- `rewarded_play.svg`: explicit rewarded-ad action

Use these only in opt-in/rewarded or post-match surfaces. Never overlay them on an active guessing turn.
