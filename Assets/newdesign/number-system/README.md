# Number system

Gameplay graphics for the narrowing interval:

- `range_track.svg`: 1–100 interval with ticks and active range
- `guess_marker.svg`: current guess / target marker
- `arrow_higher.svg`: cyan higher action
- `arrow_lower.svg`: magenta lower action
- `history_correct.svg`
- `history_higher.svg`
- `history_lower.svg`

Use the assets with localized labels from `L10n.cs`; SVG text is only a visual fallback and should not replace runtime localization.
