# Result states

Reusable 1080x620 result banners for the match-end panel and share card:

- `result_win.svg`: cyan/green success with gold trophy cues
- `result_lose.svg`: magenta/violet loss state with a friendly rematch prompt
- `result_draw.svg`: cyan/gold neutral state with a rematch prompt

Keep the score, streak and action buttons outside this banner so the same state asset works in solo, PvP, rematch and share flows.
