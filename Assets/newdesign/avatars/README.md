# Avatar frames and player/opponent states

## Frames

- `frame_player.svg`: cyan/blue player identity
- `frame_opponent.svg`: magenta/violet opponent identity
- `frame_neutral.svg`: neutral lobby/loading state
- `frame_locked.svg`: unavailable/disconnected/locked state

## State overlays

- `state_ready.svg`
- `state_thinking.svg`
- `state_winner.svg`
- `state_loser.svg`
- `state_disconnected.svg`

Frames are 256x256 overlays intended to sit behind existing portrait art. State badges are 256x92 and can be positioned beneath the avatar or next to the player card. Keep the player/opponent color roles consistent across solo and PvP.
