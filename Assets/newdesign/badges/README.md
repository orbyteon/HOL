# Profile and division badges

## Competitive divisions

- Bronze
- Silver
- Gold
- Platinum
- Diamond
- Master

Division badges are shield-shaped to read clearly at small sizes and to distinguish rank from cosmetic achievements.

## Profile achievements

- First Win
- Streak
- Perfect Run
- Lock Master
- Friend Maker

Use division badges beside the player name/rating. Use profile badges in the profile page, result summary, leaderboard rows and share card.
