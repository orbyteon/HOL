# Navigation icon set

Five navigation destinations with active and inactive SVG variants:

- Home
- Play
- Friends
- Store
- Profile

All icons use a 96x96 viewBox and are designed for a minimum 48dp touch target. The central Play action uses the larger highlighted treatment. Inactive icons use muted text color; active variants use the destination accent.

Recommended runtime mapping:

- Home: `nav_home_active.svg` / `nav_home_inactive.svg`
- Play: `nav_play_active.svg` / `nav_play_inactive.svg`
- Friends: `nav_friends_active.svg` / `nav_friends_inactive.svg`
- Store: `nav_store_active.svg` / `nav_store_inactive.svg`
- Profile: `nav_profile_active.svg` / `nav_profile_inactive.svg`
